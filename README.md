# Криминальная Россия — Путь Сильвестра

Браузерная криминальная стратегия о сибиряке, который бежал из закрытого на карантин Иркутска в Москву — и решил, что этот город будет его.

> **18+ · Игровой вымысел.** Все персонажи, организации, события и рейтинг выдуманы. Игра не связана с реальными людьми, компаниями или журналом Forbes.

## Сюжет

В Иркутске вспыхнула чума. Сильвестр, двадцать шесть лет, грузчик с рынка, купил справку и сел на последний поезд до Москвы. Через сутки въезд в город закрыли.

В кармане — $300, в голове — обещание матери вернуться. В Москве его встречает Мафия — группировка, которая держит юг города, и у которой нет ни малейшего желания делиться.

Путь: рынок в Люблино → первая бригада → районы → стрелка с Бароном → коронация → дом на Рублёвке → **$2,5 млрд и 52-е место в Forbes Россия**.

## Играть

Откройте `index.html` в браузере. Никаких сборок, зависимостей и установки — чистый HTML/CSS/JS.

Локально:

```bash
# любой статический сервер, например
python -m http.server 8080
# затем http://localhost:8080
```

Или просто двойной клик по `index.html` — всё работает и по `file://`.

## Как играть

| Ресурс | Что делает |
|---|---|
| **Наличные** | покупки, найм, взятки |
| **Капитал** | наличные + бизнесы + активы; по нему считается место в списке |
| **Дела** | 3 действия в день (4 после найма секретаря) |
| **Репутация** | открывает наёмников, связи и главы сюжета |
| **Розыск** | 100% — облава; снижается легальным бизнесом и адвокатом |
| **Медиа** | повышает доход с районов |

**Разделы**

- **Штаб** — сюжетная глава, сводка, быстрые действия.
- **Улица** — дела (от телефонов до тендеров) и бригада.
- **Бизнес** — легальные точки с ежедневным доходом и снижением розыска; статусные активы.
- **Районы** — штурм районов Мафии. Шанс = сила бригады против силы Мафии. Районы можно потерять.
- **Связи** — тётя Клава, адвокат, журналистка, банкир, политтехнолог, секретарь.
- **Forbes** — вымышленный рейтинг и ваша позиция в нём.

Каждый день: доход, содержание бригады, восстановление, снижение розыска. Мафия контратакует, полиция открывает дела, случаются события.

Прогресс сохраняется в `localStorage` автоматически.
